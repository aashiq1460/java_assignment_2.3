# Java Assignment 2.3 – Library Management System

This project is a simple Java library management system.

## Completed Tasks

- Task 1: Library and Books Association
- Task 2: Book Borrowing System
- Task 3: Book Availability Check
- Task 4: Book Ratings and Reviews
- Task 5: Library Statistics
- Task 6: Library Users

## Java Classes

- `Book.java` – Stores book information, ratings, and reviews.
- `Library.java` – Manages books, borrowing, returns, statistics, and users.
- `User.java` – Stores user information and borrowed books.
- `LibraryMain.java` – Tests the library management system.

## How to Run

Run `LibraryMain.java` in IntelliJ IDEA to test the program.
